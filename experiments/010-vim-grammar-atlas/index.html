command grammar · 명령 파이프라인

토큰을 누르면 그 원리를 다루는 장으로 이동해요

reading rule · 읽는 법

각 장은 핵심 명제 → 내부 모델 → 확인 질문 → 오해 교정 → :help 순서예요. 완료는 “외웠다”가 아니라 자기 말로 모델을 설명할 수 있다는 뜻이에요.
