experiment #004

포켓몬 타입 퀴즈 · Poké Type Quiz

랜덤으로 뜨는 타입 조합을 보고, 그 조합인 포켓몬을 제한 시간 안에 최대한 많이 외칩니다. 조합을 전부 맞추면 +5초와 함께 다음 문제로. 막히면 패스.

Random types appear — name every Pokémon with that exact combo. Clear a combo for +5s. Pass when stuck.

타입이 달라지는 리전 폼(알로라·가라르·히스이·팔데아)·메가진화·원시회귀·로토무 폼도 출제 — 리전 폼은 접두어 없이 "윈디"만 써도 타입이 맞으면 인정됩니다. 쉬움·보통의 목록은 최종 진화형 기준이지만 타입이 일치하면 미진화체도 정답 — 같은 타입 라인은 한 칸으로 묶이고(주리비얀 → 샤로다), 목록에 없는 라인은 +1 보너스(불꽃 단일의 뚜꾸리). 한국어/영어 모두 인정, 띄어쓰기·기호는 무시. 맞추면 일러스트가 짠 하고 나타납니다.
