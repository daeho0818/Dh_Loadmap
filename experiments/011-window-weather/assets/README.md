# Photographic scenery assets

Generated with the built-in `image_gen` tool on 2026-10-14 for this experiment. These are AI-generated scenes, not photographs of a verified real location. The sunny scene establishes the locked composition; the four weather variants edit that scene while preserving the room and window geometry. Runtime weather effects are drawn separately. The time slider grades the lighting of these afternoon plates rather than retrieving actual weather or regenerating images.

Files: `sunny.png`, `rain.png`, `snow.png`, `fog.png`, `storm.png`.

Constraints: clean image only, no interface, no labels, no text, no logos or watermark, no borders outside the scene, no collage. All glass closed. Keep foreground objects modest and leave central window view beautifully open. Do not bake in moving particles. Photographic realism is the overriding requirement.
