코블몬 여정 · Cobblemon Journey

마인크래프트 × 포켓몬(Cobblemon) — 설치부터 메가진화까지. 도전과제에 체크하며 나만의 여정을 기록하는 페이지.

Install guide, play guide, and a checkable quest roadmap for the Cobblemon mod.

① 설치 가이드 (CurseForge 기반)

⚠ 부팅 크래시 해결 — "Failed to load registries"

싱글플레이 진입 시 Errors in registry mega_showdown:mega가 뜬다면 호환 팩 세대 불일치다. AllTheMons x Mega Showdown [v2.8.1]은 구버전 Mega Showdown용 — 모드가 Mega Showdown 1.8.x라면 팩도 v3.6.1 (MSD 1.8.0+ 대응)으로 교체해야 한다. datapacks/와 resourcepacks/ 양쪽의 zip을 모두 새 버전으로 바꾸면 끝.

구성버전위치

Cobblemon (본체)1.7.3mods/

규칙: 모드는 mods, 팩은 datapacks+resourcepacks 짝으로. 팩 페이지의 "Compatible with Mega Showdown vX+" 표기를 항상 내 모드 버전과 대조할 것 — 이번 크래시의 교훈.

  1. CurseForge 앱 설치 → Minecraft → Create Custom Profile → Fabric / 1.21.1.
  2. 프로필의 Add More Content(또는 폴더 열기 → mods/)에서 위 표의 모드들을 추가. 의존성(Fabric API 등)은 CurseForge가 같이 받아준다.
  3. 프로필 우클릭 → Open Folder → datapacks/, resourcepacks/ 폴더에 팩 zip 배치. (Global Packs 모드가 datapacks/를 모든 월드에 자동 적용해준다)
  4. 실행 → 리소스팩 화면에서 AllTheMons 팩 활성화 → 싱글플레이 진입 확인.
  5. 크래시가 나면 logs/latest.log에서 Registry loading errors 위쪽을 볼 것 — 범인(어떤 팩의 어떤 파일인지)이 거기 적혀 있다.

② 플레이 가이드

정확한 조합법은 게임 안에서 확인하는 게 최신·확실 — 레시피북/JEI에서 아이템명 검색, 스폰 정보는 스마트폰 모드의 도감으로.

첫 1시간 — 포켓볼과 첫 포획
  • 아프리콘(Apricorn) 나무를 찾아 열매를 수확 — 포켓볼의 재료다. 묘목을 심어 농장을 만들면 두고두고 편하다.
  • 아프리콘 + 구리/철 계열 재료로 포켓볼 제작 (레시피북에서 "poke ball" 검색).
  • 야생 포켓몬과 배틀해 체력을 깎은 뒤 포켓볼 투척 — 잔여 체력이 낮을수록, 상태이상일수록 잘 잡힌다. 초반 필드몬은 그냥 던져도 잘 들어간다.
  • 힐링 머신과 PC를 일찍 만들 것 — 회복과 보관의 거점. 거점 침대 옆에 두면 루틴이 잡힌다.
  • 스타팅 포켓몬은 월드 시작 시 선택 — 성능보다 애정으로 고르자. 어차피 금방 여섯 마리가 된다.
성장 — 진화, 도감, 스마트폰
  • 배틀 승리로 경험치 획득. 진화 조건은 레벨 외에도 아이템·시간대·통신(링크 케이블) 등 다양 — 도감/위키 참고.
  • 스마트폰 모드: 도감·스폰 바이옴·시간대 확인이 게임 안에서 가능. "이 몬 어디서 나와?"는 폰부터.
  • 포켓몬마다 바이옴·시간·날씨 스폰 조건이 있다 — 낮/밤, 비 오는 날, 특정 바이옴 원정이 자연스러운 탐험 루프가 된다.
  • 낚싯대로 물 포켓몬 낚시, 땅속 화석은 부활 장치로 복원 — 채굴·낚시가 전부 포켓몬과 연결된다.
  • MissingMon·MythsAndLegends 팩이 추가 몬과 전설 소환 구조물을 더해준다 — 후반 콘텐츠.
메가진화 — Mega Showdown 핵심 루트
  • 메가사이트(Megasite): 지하 Y5~Y20에 생성되는 전용 구조물. 중심부에서 키스톤(Key Stone)과 원석 메가스톤을 얻는다.
  • 메가 브레슬릿 제작: 철 주괴 5 + 다이아몬드 1 + 키스톤 1 + 아프리콘 2 (색상은 취향).
  • 인벤토리의 액세서리 슬롯(왼쪽 Mega 슬롯)에 브레슬릿 장착.
  • 포켓몬별 전용 메가스톤을 제작해 그 포켓몬에게 지니게 한다 (공유 불가).
  • 배틀에서 Fight → 왼쪽 아래 Mega Evolve 아이콘 → 기술 선택 → 그 턴에 메가진화.
  • 예외: 레쿠자는 메가스톤 없이 기술 "용의 승천"만 배우면 메가진화 가능.
